# pdf2sheets_api

FastAPI web app that accepts botanical PDF sheets, runs a Datalab pipeline, saves the intermediate Datalab HTML outputs, parses the selected full/default HTML artifact, and returns a zip containing both the final Excel sheet and debugging HTML files.

## What The App Returns

Uploading a PDF downloads:

```text
converted-<run-id>.zip
```

Inside the zip:

```text
converted.xlsx
intermediate_html/default.html
intermediate_html/<run-id>-01.html
intermediate_html/<run-id>-02.html
...
```

`default.html` is generated by the app as a copy of the best full-document Datalab artifact. The original Datalab intermediate files are also included.

## Datalab Setup

1. Log in to Datalab.
2. Go to your account/API settings.
3. Generate an API key.
4. Copy the key.
5. Create a local `.env` file from the example:

```bash
cp .env.example .env
```

6. Edit `.env` and paste your key:

```env
DATALAB_API_KEY=your_real_datalab_api_key
DATALAB_PIPELINE_ID=pl_4AHLbwoxranz
DATALAB_PIPELINE_VERSION=3
```

Do not commit `.env`. It is ignored by git.

## Install

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run The Website

```bash
python3 -m uvicorn main:app --reload
```

Open:

```text
http://127.0.0.1:8000
```

Upload a PDF. The browser will download a zip with the parsed Excel and intermediate HTML.

## Datalab API Behavior

The app calls the configured Datalab pipeline with:

```python
pipeline_id = "pl_4AHLbwoxranz"
version = 3
skip_cache = true
output_format = "html"
```

The direct SDK equivalent is:

```python
from datalab_sdk import DatalabClient, ConvertOptions

client = DatalabClient()

options = ConvertOptions(
    output_format="html",
    mode="balanced",
    paginate=True,
)

result = client.convert("document.pdf", options=options)
print(result.html)
```

For this app, the important part is requesting HTML output from Datalab so the parser can read rendered table pages.

## Parser Notes

The parser:

- selects the best full intermediate artifact as `default.html`
- builds `converted.xlsx` from that selected default artifact only
- still saves all raw Datalab intermediate files for debugging
- handles real HTML tables
- handles Markdown tables wrapped in HTML
- ignores map tables, legends, metadata snippets, and species-code tables
- removes crossed-out rows and full-X placeholder rows
