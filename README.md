## What The App Returns

Uploading a PDF downloads:

```text
<input-file-name>.zip
```

Inside the zip:

```text
<input-file-name>.xlsx
<input-file-name>/default.html
<input-file-name>/<input-file-name>-01.html
<input-file-name>/<input-file-name>-02.html
...
```

The Excel workbook and main worksheet are named after the uploaded PDF file. `default.html` is generated by the app as a copy of the best full-document Datalab artifact. The original Datalab intermediate files are also included.

## Datalab Setup

1. Log in to Datalab.
2. Go to your account/API settings.
3. Generate an API key.
4. Copy the key.
5. Keep the key private. Do not paste it into GitHub, Slack, email, or the source code.

This app does not require access to the saved pipeline in the original developer account. It recreates the same playground settings with the Datalab Convert API.

## Local Setup From Scratch

### 1. Install Or Check Python

This app needs Python 3.10 or newer.

On macOS, open Terminal and check whether Python is already installed:

```bash
python3 --version
```

If that command prints a Python version like `Python 3.11.8`, continue to the next step.

If macOS says the command was not found, install Python from:

```text
https://www.python.org/downloads/macos/
```

Download the latest stable Python 3 installer, open the `.pkg` file, and follow the prompts. Close and reopen Terminal after installing, then run:

```bash
python3 --version
```

On Windows, open PowerShell and check whether Python is already installed:

```powershell
py --version
```

If that does not work, try:

```powershell
python --version
```

If one of those commands prints a Python version like `Python 3.11.8`, continue to the next step.

If Windows says Python was not found, install Python from:

```text
https://www.python.org/downloads/windows/
```

Download the latest stable Python 3 installer. On the first installer screen, check **Add python.exe to PATH**, then click **Install Now**. Close and reopen PowerShell after installing, then run:

```powershell
py --version
```

### 2. Open A Terminal

On macOS:

1. Press `Command + Space`.
2. Type `Terminal`.
3. Press `Enter`.

On Windows:

1. Press `Windows`.
2. Type `PowerShell`.
3. Press `Enter`.

### 5. Install Requirements

macOS:

```bash
pip install -r requirements.txt
```

Windows:

```powershell
python -m pip install -r requirements.txt
```

### 6. Create The `.env` File

You can either copy the example:

macOS:

```bash
cp .env.example .env
```

Windows:

```powershell
Copy-Item .env.example .env
```

Or create it manually.

macOS:

```bash
nano .env
```

Windows:

```powershell
notepad .env
```

Paste this into the file:

```env
DATALAB_API_KEY=your_real_datalab_api_key
DATALAB_CONVERT_MODE=accurate
DATALAB_OUTPUT_FORMAT=html
DATALAB_EXTRAS=table_cell_bboxes
```

Replace:

```text
your_real_datalab_api_key
```

with your real Datalab API key. The other values recreate the Datalab playground options used for this parser.

To save and exit `nano` on macOS:

```text
Ctrl + O
Enter
Ctrl + X
```

In Notepad on Windows, use **File > Save**, then close Notepad.

Do not commit `.env`. It is ignored by git.

The `.env.example` file is safe to commit because it contains placeholders only. The real `.env` file should stay only on your computer or on the computer/server running the app.

### 7. Check That `.env` Exists

macOS:

```bash
ls -la .env
```

Windows:

```powershell
Get-Item .env
```

You should see `.env` listed.

### 8. Run The Website

macOS:


Windows:


On macOS, find it:


Stop the listed process ID:

```bash

```

On Windows, find it:

```powershell
netstat -ano | findstr :8000
```

Stop the listed process ID:

```powershell
taskkill /PID <PID> /F
```

Then run the website again.

macOS:

```bash

```

Windows:

```powershell
python -m uvicorn main:app --reload
```

Or run on another port:


Windows:

## Datalab API Behavior

The app calls Datalab Convert directly with these form fields:

```text
mode=accurate
output_format=html
paginate=true
merge_cross_page=false
disable_image_captions=true
disable_image_extraction=true
extras=table_cell_bboxes
skip_cache=true
additional_config={"keep_pageheader_in_output": false, "keep_pagefooter_in_output": false}
```

These settings mirror the Datalab playground setup: Accurate mode, Paginate on, Disable Image Captions on, Disable Image Extraction on, and Table Cell Bboxes on. The app does not need a saved Datalab pipeline ID.

## Parser Notes

The parser:

- selects the best full intermediate artifact as `default.html`
- builds `<input-file-name>.xlsx` from that selected default artifact only
- still saves all raw Datalab intermediate files for debugging
- handles real HTML tables
- handles Markdown tables wrapped in HTML
- ignores map tables, legends, metadata snippets, and species-code tables
- removes crossed-out rows and full-X placeholder rows

## CLI Upload Test

With the website running, you can test an upload from Terminal:

macOS:

```bash
curl -X POST \
  -F "file=@/path/to/document.pdf;type=application/pdf" \
  http://127.0.0.1:8000/convert \
  --output document.zip
```

Windows PowerShell:

```powershell
curl.exe -X POST `
  -F "file=@C:\path\to\document.pdf;type=application/pdf" `
  http://127.0.0.1:8000/convert `
  --output document.zip
```

Unzip:

macOS:

```bash
unzip document.zip
```

Windows PowerShell:

```powershell
Expand-Archive document.zip -DestinationPath document-output
```
